# Feature map (verifier, branch improve/verify)

Every user-facing feature, how to start it, what the user does, and what they should see. Executed against fictional data only (Mira Tan, F17) on spare ports, never the live n8n (5678), the private API (18768) or real accounts.

Status values: **green** (seen working, evidence linked), **finding** (open, see `findings.md`, owner named), **deferred** (blocked by the demo guard or a human-only step, owner and re-verify time named), **pending** (not run yet).
